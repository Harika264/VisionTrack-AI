# 🎯 VisionTrack AI

## Intelligent Computer Vision & Real-Time Video Analytics

VisionTrack AI is a computer vision application that performs object detection, multi-object tracking, trajectory visualization, vehicle counting, performance benchmarking, and model evaluation from uploaded videos.

The application uses YOLO11n for object detection and tracking and provides an interactive Streamlit dashboard for video analytics.

---

## 🚀 Features

- 🎯 YOLO11n-based object detection
- 👤 Person detection and tracking
- 🚗 Car detection and tracking
- 🚚 Truck detection and tracking
- 🆔 Multi-object tracking with unique IDs
- 🛤️ Object trajectory visualization
- ↘️ Vehicle IN counting
- ↗️ Vehicle OUT counting
- ⚡ Real-time FPS monitoring
- 🧠 YOLO inference latency measurement
- 📊 Model performance benchmarking
- 🔬 Model evaluation
- ⚙️ Automatic inference-size optimization
- 📈 Interactive Streamlit dashboard
- 📄 JSON analytics reports
- 📊 CSV analytics reports
